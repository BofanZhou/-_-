一、数据先说话：国奖论文都在用什么

总排行 TOP5（论文级出现率 | 题目级，n=259 篇/73 题）：
  • 最小二乘拟合 27.4%（题目级 52.1%）、回归 24.3%、假设检验 22.4%、灵敏度 22.0%（题目级 53.4% 全场第一）、多目标优化 20.5%；
  • 第二梯队（10–17%）：聚类、遗传算法、稳定性、图论、微分方程、神经网络、时间序列、插值、线性规划、蒙特卡洛。
来源：方法选用图谱（编辑器打开）
反直觉发现：评价四件套是「市面神话」 AHP 7.3%、熵权 3.1%、TOPSIS 1.5%、模糊评价 3.1%——培训圈人人在讲的「评价四件套」，在国奖论文里出现率远低于想象。D 题更依赖自建指标体系，而不是套现成方法。别把它当主武器。

二、按题型选主方法（口诀版）

题型默认主方法（出现率实证）含义
A 题（机理）最小二乘拟合 40.5% + 微分方程/灵敏度 29.1% + 假设检验 25.3%坐标-物理量-效率链，拟合+检验是标配
B 题（离散优化）多目标 28.6% + 最小二乘 25.7% + 遗传/图论/灵敏度 21.4%规划/启发式 + 多目标处理
C 题（数据统计）回归 43.5% + 假设检验 32.6% + 灵敏度 28.3%「回归 + 检验」是基本盘

搭配公式：主方法 + 1 辅助 + 1 检验。例：主=动态规划，辅=蒙特卡洛仿真，检=灵敏度/稳定性。近三年（2023–2025）走高的是蒙特卡洛、时间序列、灵敏度、稳定性——模型评价里至少做一种，评委当前就好这口。

标题 → 武器速查：优化→规划/动态规划/启发式（遗传 15.1%）· 数据→最小二乘/回归/LMM · 预测→时间序列/回归 · 机理→微分方程/几何 · 评价→假设检验/自建指标（别迷信 AHP/TOPSIS）。

三、选型三红线

① 模型服务问题：一句话写不出「为什么用它」的模型不要上——写不出判定依据，评委就知道你在堆；② 公示板纪律：每个小问必须写「主模型 + 备选模型」两个名字（手册 Step 2 验收标准）；③ 冷门只做对比：蚁群/强化学习单打独斗易被追问，当「与主方法对比」的次级方案最安全。

国奖案例（手册 Step 2/7）：2023A 的判定句范式——「变量连续且目标约束线性 → 线性规划；离散 0-1 → 整数规划；非线性多变量 → GA/PSO；多阶段 → 动态规划」。2025B 的求解设计——问题二滑窗 FFT 找频段得初值，再双角度联合非线性最小二乘精修；「初值 + 精修 + 判据」是求解设计的标准姿势。
